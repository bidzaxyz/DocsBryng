## Start in the dashboard

Open [Bryng](https://bryng.xyz/home), select the business you manage, and choose **Developer**.
Tools and permissions apply to the selected business.

## Public API and webhooks

<Info>
  Public API reference and integration guides are coming. API key and webhook creation are not available yet in the dashboard.
</Info>

We’ll document authentication, supported endpoints, request and response examples, and webhook verification here as they become available.
There is no public SDK setup or API quickstart to follow yet.

## Before you build

- Decide which business your integration will serve.
- Describe the task you want to automate and the data it needs.
- Keep credentials and private customer data out of public code and support messages.

For integration questions, [contact support](/support) with your use case.

## Manage a business today

Use the dashboard to manage [products](/portal/products), review [payments](/portal/payments), and edit [websites](/portal/websites).

## დაუკავშირდით Bryng-ს

მოგვწერეთ [help@bryng.xyz](mailto:help@bryng.xyz).
მიუთითეთ ბიზნესის სახელი, გვერდი ან ამოცანა, პრობლემის აღწერა და საჭიროების შემთხვევაში შეკვეთის ნომერი.
დეველოპერის კითხვებისთვის აღწერეთ სასურველი ინტეგრაცია.

<Warning>
  არ გამოგზავნოთ პაროლები, შესვლის კოდები, API გასაღებები, გადახდის საიდუმლო გასაღებები ან ბარათის სრული მონაცემები. ეკრანის სურათებზე დაფარეთ მომხმარებლის პირადი ინფორმაცია.
</Warning>

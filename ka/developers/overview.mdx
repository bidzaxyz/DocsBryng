## დაიწყეთ მართვის პანელიდან

გახსენით [Bryng](https://bryng.xyz/home), აირჩიეთ ბიზნესი, რომელსაც მართავთ, და გადადით **დეველოპერის** განყოფილებაში.
ხელსაწყოები და უფლებები არჩეულ ბიზნესს ეხება.

## საჯარო API და ვებჰუკები

<Info>
  საჯარო API-ის დოკუმენტაცია და ინტეგრაციის გზამკვლევები მალე დაემატება. API გასაღებისა და ვებჰუკის შექმნა მართვის პანელში ჯერ მიუწვდომელია.
</Info>

ხელმისაწვდომობის მიხედვით აქ დავამატებთ ავტორიზაციის წესებს, მხარდაჭერილ ენდპოინტებს, მოთხოვნისა და პასუხის მაგალითებს და ვებჰუკის გადამოწმების ინსტრუქციას.
საჯარო SDK-ის დაყენებისა და API-ით დაწყების ინსტრუქცია ჯერ არ არის.

## დაგეგმეთ ინტეგრაცია

- განსაზღვრეთ, რომელ ბიზნესს მოემსახურება ინტეგრაცია.
- აღწერეთ ამოცანა და მონაცემები, რომლებიც დასჭირდება.
- არ განათავსოთ გასაღებები და მომხმარებლის პირადი მონაცემები საჯარო კოდში ან მხარდაჭერის შეტყობინებებში.

ინტეგრაციის შესახებ კითხვებისთვის [მოგვწერეთ](/ka/support) და აღწერეთ თქვენი ამოცანა.
